# ADR-002 · 无 UI 库，手写 CSS（终版）

- 状态：已定稿（M0，2026-11-02）
- 依据：《工程蓝图》§2.4；《综合方案修订定稿 v2》§2.1（沿用）

## 决策

CSS Custom Properties 做主题变量 + BEM 风格的朴素类名约定，不引入任何 UI 组件库与 CSS 框架。

## 理由 / 淘汰项

- 淘汰 Tailwind：构建链多一层依赖、类名噪音；两个界面的体量手写 CSS 更直接。
- 淘汰一切组件库：体积与定制交互（大按钮、段落条、时间刻度条打点）本来就要手写，组件库只会碍事。
- DOM 工具收敛在 `src/ui/dom.ts`（h / on / mount，约 50 行），UI 组件只读 store、只发 action。

## 连带影响

- 波形渲染方案已砍除（见 ADR-005），编辑器打点改在时间刻度条上进行，纯 CSS/Canvas 绘制、零音频解码。
